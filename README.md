# 💳 Apple Pay Expense Tracker

Трекер трат: каждая оплата через Apple Pay автоматически попадает в «блокнотик», сама раскладывается по категориям и на дашборде видно, куда уходят деньги.

```
iPhone: оплата Apple Pay
   │  (автоматизация «Транзакция» в приложении «Быстрые команды»)
   ▼
POST /api/transactions  ──►  сервер (FastAPI + SQLite)
                               ├─ разбирает сумму и валюту ("1 250,50 ₸")
                               ├─ определяет категорию по магазину
                               └─ сохраняет в базу
   ▲
   │  уведомление на телефоне: «Продукты: 5 400 ₸ — Magnum»
   │
Дашборд в браузере: диаграмма по категориям, список трат, смена категории, экспорт в CSV
```

## Что умеет

- **Автоматически ловит** оплаты Apple Pay: ничего не нужно вводить руками.
- **Раскладывает по категориям**: продукты, кафе, такси, топливо, подписки и т.д. Правила лежат в [`app/categories.json`](app/categories.json), там уже есть популярные магазины Казахстана и России.
- **Учится**: если поменять категорию у магазина на дашборде, он запомнит выбор и применит его ко всем прошлым и будущим покупкам там.
- **Дашборд** под телефон (светлая и тёмная тема): сумма за месяц, диаграмма, топ категорий, список операций по дням.
- **Несколько валют**: ₸, ₽, $, € и т.д. считаются раздельно.
- **Экспорт в CSV** для Excel / Numbers / Google Sheets.

## 1. Запуск сервера

Серверу нужен постоянный адрес в интернете, чтобы iPhone мог отправлять туда транзакции.

### Локально (проверить, как работает)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впиши свой API_TOKEN
set -a; source .env; set +a
uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000
```

Открой http://localhost:8000 и введи токен.

Сгенерировать надёжный токен можно так: `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`

### Через Docker (для постоянной работы)

```bash
cp .env.example .env   # впиши API_TOKEN
docker compose up -d --build
```

База хранится в `./data/expenses.db`. Этот файл и есть твой «блокнотик», его стоит иногда бэкапить.

### Где разместить

| Вариант | Как |
|---|---|
| VPS (любой, от ~$4/мес) | `docker compose up -d` + домен и HTTPS через Caddy/nginx |
| Домашний ПК / Raspberry Pi | запускаешь Docker + [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) или [Tailscale Funnel](https://tailscale.com/kb/1223/funnel), чтобы получить https-адрес без белого IP |
| Railway / Fly.io | деплой из Dockerfile, **обязательно подключи volume** на `/data`, иначе база сотрётся при перезапуске |

Используй **HTTPS**, потому что в запросе передаётся токен.

## 2. Настройка iPhone (Быстрые команды)

Нужен iOS 17 или новее.

1. Открой **Быстрые команды → Автоматизация → «+» → Транзакция** (*Transaction*).
2. Выбери карты из Wallet, которые нужно отслеживать. Категории и продавцов не трогай, пусть срабатывает на всё.
3. Выбери **«Запускать сразу»** (*Run Immediately*) → **Далее → Новая пустая команда**.
4. Добавь действие **«Получить содержимое URL»** (*Get Contents of URL*):
   - **URL:** `https://твой-сервер/api/transactions`
   - **Метод:** `POST`
   - **Заголовки:** `Authorization` = `Bearer ТВОЙ_API_TOKEN`
   - **Тело запроса:** `JSON`, поля (все типа *Текст*):
     | Ключ | Значение (переменная) |
     |---|---|
     | `merchant` | Ввод команды → **Продавец** (*Merchant*) |
     | `amount` | Ввод команды → **Сумма** (*Amount*) |
     | `card` | Ввод команды → **Карта или пропуск** (*Card or Pass*) |
     | `name` | Ввод команды → **Имя** (*Name*), по желанию |
5. *(По желанию)* Добавь **«Получить значение из словаря»** с ключом `message` и затем **«Показать уведомление»**. После каждой оплаты придёт пуш вроде «Продукты: 5 400 ₸ — Magnum».

Названия пунктов могут немного отличаться в зависимости от версии iOS. Сумму сервер понимает в любом формате (`1 250,50 ₸`, `₸1,250.50`, `$12.99`, `5000`). Если валюту не удалось распознать, берётся `DEFAULT_CURRENCY`.

**Проверка без оплаты:**

```bash
curl -X POST https://твой-сервер/api/transactions \
  -H "Authorization: Bearer ТВОЙ_API_TOKEN" -H "Content-Type: application/json" \
  -d '{"merchant": "Magnum", "amount": "5 400 ₸", "card": "Kaspi Gold"}'
```

### Ограничения, о которых стоит знать

- Автоматизация срабатывает на оплаты **через Wallet/Apple Pay на этом iPhone** (терминал, иногда онлайн). Оплаты картой напрямую, **Kaspi QR**, переводы и оплаты с Apple Watch без iPhone рядом сюда не попадут. Их можно добавить тем же `curl` / отдельной Быстрой командой.
- Возвраты не ловятся. Лишнюю операцию можно удалить на дашборде.

## 3. Дашборд

Открой `https://твой-сервер/` в Safari, введи токен. Чтобы открывать как приложение: **Поделиться → На экран «Домой»**.

- ‹ › переключают месяц
- тап по категории (или сектору диаграммы) фильтрует операции
- выпадающий список у операции меняет категорию, «+ Новая категория…» создаёт свою
- **Экспорт CSV** выгружает месяц в файл

## Категории

Правила в [`app/categories.json`](app/categories.json): `категория → ключевые слова`. Поиск идёт по целым словам без учёта регистра, побеждает первое совпадение сверху вниз. Если ничего не подошло, операция попадает в «Другое». Добавь свои любимые магазины и перезапусти сервер.

Второй способ (удобнее): просто меняй категорию на дашборде, сервер запомнит.

## API

Все запросы, кроме `/` и `/health`, требуют заголовок `Authorization: Bearer <API_TOKEN>`.

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/transactions` | добавить: `{merchant, amount, currency?, card?, name?, date?}` |
| `GET` | `/api/transactions?month=2026-09&category=Продукты` | список операций |
| `PATCH` | `/api/transactions/{id}` | `{category, remember: true}` и/или `{note}` |
| `DELETE` | `/api/transactions/{id}` | удалить |
| `GET` | `/api/summary?month=2026-09` | итоги по категориям и дням |
| `GET` | `/api/categories` | список категорий |
| `GET` | `/api/export.csv?month=2026-09` | выгрузка CSV |

Интерактивная документация: `/docs`.

## Настройки (`.env`)

| Переменная | По умолчанию | |
|---|---|---|
| `API_TOKEN` | (обязательно) | секрет для iPhone и дашборда |
| `TIMEZONE` | `Asia/Almaty` | часовой пояс для группировки по дням |
| `DEFAULT_CURRENCY` | `KZT` | если валюту не удалось распознать |
| `DB_PATH` | `data/expenses.db` | путь к базе SQLite |
