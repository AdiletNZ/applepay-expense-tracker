# Вариант без сервера: Google Таблица

🇬🇧 [English](../README.md) · 🇷🇺 Русский

Покупки по Apple Pay сами записываются в Google Таблицу и раскладываются по категориям. На отдельном листе видно итоги за месяц с диаграммой. Бесплатно, нужен только Google-аккаунт.

**Что получится:**

| Лист | Что там |
|---|---|
| **Итоги** | **только текущий месяц**: сумма, траты по категориям с долей в %, круговая диаграмма. 1-го числа сам переключается на новый месяц |
| **Операции** | все покупки: дата, магазин, сумма, валюта, категория, карта |
| **Категории** | какие слова в названии магазина относят его к какой категории, можно дописывать свои |
| **Правила** | магазины, у которых ты вручную поменял категорию (заполняется само) |
| **История** | все покупки лентой, как в банковском приложении: **свежие сверху**, по месяцам с суммой за месяц. Дата, время, магазин, категория, сумма, карта |
| **История (Диаграммы)** | **кругляш за каждый месяц**, как в «Итогах», а рядом сколько всего ушло и разбивка по категориям. Свежие месяцы сверху |

**Всё обновляется само**: после каждой покупки, после любой правки на листе «Операции» (категория, сумма, удалённая строка) и раз в сутки ночью для надёжности. Ничего запускать руками не нужно. Меню **💳 Трекер → 🔄 Обновить историю** нужно только если захочешь пересобрать всё принудительно.

⏱ Займёт около 10 минут. Часть 1 удобнее делать **на компьютере**, часть 2 делается на iPhone.

## Часть 1. Таблица (на компьютере)

### 1.1 Создай таблицу

Открой **[sheets.new](https://sheets.new)** и назови таблицу, например, «Мои траты».

### 1.2 Вставь скрипт

1. В меню таблицы: **Расширения → Apps Script**. Откроется редактор кода.
2. Удали всё, что там написано.
3. Открой **[Code.gs](https://raw.githubusercontent.com/AdiletNZ/applepay-expense-tracker/main/google-sheets/Code.gs)**, выдели всё (Ctrl+A / Cmd+A), скопируй и вставь в редактор.
4. В самом начале найди строку:
   ```js
   const TOKEN = 'ВСТАВЬ_СВОЙ_ТОКЕН';
   ```
   и замени `ВСТАВЬ_СВОЙ_ТОКЕН` на свой токен (кавычки оставь):
   ```js
   const TOKEN = 'твой-токен-здесь';
   ```
5. Сохрани: 💾 или Ctrl+S / Cmd+S.

### 1.3 Запусти настройку

1. Сверху, рядом с кнопкой **▶ Выполнить**, есть выпадающий список функций. Выбери в нём **`setup`** (он первый в списке).
2. Нажми **▶ Выполнить**.
3. Google спросит разрешение. Это нормально, ведь скрипт твой собственный:
   - **Проверить разрешения** → выбери свой аккаунт
   - появится «Приложение не проверено Google» → **Дополнительные настройки** → **Перейти на страницу «…» (небезопасно)**
   - **Разрешить**
   Google также попросит разрешение **запускаться по расписанию и при изменениях таблицы**: благодаря этому история обновляется сама.
4. Вернись в таблицу: там появятся листы **Итоги, Операции, Категории, Правила, История, История (Диаграммы)**, а сверху меню **💳 Трекер** (если его нет, обнови страницу).

> Для проверки можно выбрать функцию **`testTransaction`** и нажать ▶. На листе «Операции» появится тестовая покупка Magnum. Потом просто удали эту строку.

### 1.4 Опубликуй, чтобы iPhone мог отправлять покупки

1. В редакторе справа сверху: **Начать развертывание → Новое развертывание**.
2. Нажми ⚙️ рядом с «Выберите тип» → **Веб-приложение**.
3. Заполни:
   - **Запуск от имени:** Я
   - **У кого есть доступ:** Все (именно «Все», а не «Все, у кого есть аккаунт Google»)
4. **Начать развертывание** → скопируй **URL веб-приложения** (заканчивается на `/exec`).
5. Проверь: открой этот URL в браузере. Должно появиться `"Трекер трат работает ✅"`.

Отправь этот URL себе на iPhone (например, в Заметки), он понадобится дальше.

> «Доступ: Все» значит, что отправить запрос по ссылке может кто угодно, но без правильного токена скрипт ничего не запишет. Не публикуй ссылку и токен.

## Часть 2. iPhone (Быстрые команды)

Нужен **iOS 17 или новее**.

### 2.1 Создай автоматизацию

1. Открой приложение **«Быстрые команды»** → вкладка **«Автоматизация»** (внизу).
2. Нажми **«+»** (или «Новая автоматизация»).
3. Пролистай и выбери **«Транзакция»**.
4. **Карты:** отметь свои карты из Wallet. Категории ниже оставь **все отмеченными**.
5. Если внизу есть **«Запускать сразу»**, выбери его (иначе каждый раз придётся подтверждать). В некоторых версиях iOS этот пункт появляется позже, см. шаг 2.4. → **«Далее»**.
6. **«Новая пустая команда»** / **«Создать новую быструю команду»**.

### 2.2 Отправка покупки в таблицу

1. **«Добавить действие»** → в поиске набери **URL** → выбери **«Получить содержимое URL»**.
2. Нажми на синее слово **URL** и вставь ссылку `…/exec` из шага 1.4.
3. Нажми на стрелочку **›** у этого действия, чтобы раскрыть настройки:
   - **Метод:** `POST`
   - **Текст запроса:** `JSON`
4. Нажми **«Добавить новое поле» → «Текст»** и добавь 4 поля:

   | Ключ | Значение |
   |---|---|
   | `token` | твой токен (просто текстом) |
   | `merchant` | нажми на поле значения → над клавиатурой выбери **«Ввод команды»**, затем нажми на него → **«Продавец»** |
   | `amount` | так же **«Ввод команды»** → **«Сумма»** |
   | `card` | так же **«Ввод команды»** → **«Карта или пропуск»** |

   (Названия могут чуть отличаться в зависимости от версии iOS, главное выбрать продавца, сумму и карту.)

### 2.3 Уведомление о покупке (по желанию, но удобно)

1. **«Добавить действие»** → **«Получить значение из словаря»**. Ключ: `message`.
2. **«Добавить действие»** → **«Показать уведомление»** → в текст вставь переменную **«Значение словаря»**.

После каждой оплаты будет приходить пуш вроде **«Продукты: 5 400 ₸ — Magnum»**.

В конце нажми **«Готово»**.

### 2.4 Немедленный запуск

Во вкладке «Автоматизация» открой свою автоматизацию → выбери **«Немедленный запуск»** / **«Запускать сразу»** и выключи **«Уведомлять о запуске»** → «Готово».

### 2.5 Проверка

Оплати что-нибудь через Apple Pay, хоть кофе ☕ Через пару секунд покупка появится на листе «Операции», а итоги обновятся. Таблицу удобно смотреть в приложении **Google Таблицы** на iPhone.

## Как пользоваться

- **Поменять категорию:** на листе «Операции» выбери другую в выпадающем списке. Скрипт запомнит этот магазин (лист «Правила») и поменяет категорию у всех его покупок, прошлых и будущих. Можно вписать и свою категорию.
- **Прошлые месяцы:** лист **«История»** (цифры и диаграммы) или **«История (Диаграммы)»** (только диаграммы).
- **Валюта:** в **B2** на «Итогах» (`KZT`, `USD`, …). Итоги и история считаются в этой валюте.
- **Свои магазины:** допиши ключевые слова на листе «Категории» через запятую. Категории проверяются сверху вниз, побеждает первое совпадение.
- **Добавить покупку вручную** (например, Kaspi QR): просто впиши строку на лист «Операции».

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Уведомление «Неверный токен» | токен в Быстрой команде и в скрипте должен совпадать символ в символ |
| «Впиши свой токен…» | не заменил `ВСТАВЬ_СВОЙ_ТОКЕН` в начале скрипта, либо не сделал новое развёртывание после правки (см. ниже) |
| «Нет листа…» | не запустил функцию `setup` (шаг 1.3) |
| Ссылка `/exec` в браузере пишет «Не удалось открыть файл» | в браузере вошли в несколько Google-аккаунтов. Открой ссылку в окне инкогнито: если там «работает ✅», всё в порядке, iPhone будет работать |
| `TypeError: Cannot read properties of undefined` при запуске в редакторе | запустилась не та функция: выбери в списке `setup` или `testTransaction` |
| Ручной запуск автоматизации (▶) отвечает `"не передан магазин (merchant)"` | это нормально: без настоящей оплаты нет магазина и суммы. Ссылка и токен в порядке, проверяй настоящей оплатой Apple Pay |
| Непонятно, что пошло не так | временно поставь в «Показать уведомление» переменную **«Содержимое URL-адреса»** вместо «Значение словаря»: уведомление покажет полный ответ таблицы с точной ошибкой |
| В «Управлении развертываниями» кнопка **Deploy** серая | сначала нажми ✏️ **карандаш** справа сверху, потом **Version → New version** |
| В команде значение «Продавец» записывается в таблицу буквально | вставь его синей плашкой-переменной («Входные данные команды» → нажать → «Продавец»), а не печатай текстом |
| Автоматизация не срабатывает | проверь, что стоит **«Запускать сразу»** и выбраны нужные карты; Kaspi QR и переводы сюда не попадают |

**Если поменял код скрипта**, изменения заработают только после обновления развёртывания: **Начать развертывание → Управление развертываниями → ✏️ (карандаш; пока его не нажмёшь, кнопка Deploy серая) → Версия: «Новая версия» → Начать развертывание**. Ссылка при этом не меняется, а версия станет «Version 2», «Version 3»…

## Как обновиться на новую версию скрипта

1. Скопируй новый [Code.gs](https://raw.githubusercontent.com/AdiletNZ/applepay-expense-tracker/main/google-sheets/Code.gs) в редактор Apps Script вместо старого.
2. Снова впиши свой токен в строку `TOKEN` и сохрани.
3. Выбери в списке **`setup`** → **▶ Выполнить** (разреши новые права, если спросит). Покупки, категории и правила сохранятся, а «Итоги» и «История» пересоберутся.
4. Обнови развёртывание: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. **Не** «New deployment», иначе будет новая ссылка.

На iPhone ничего менять не нужно.

## Нужно ли что-то делать каждый месяц?

**Нет.** После установки всё работает само: 1-го числа «Итоги» переключаются на новый месяц, в «Истории (Диаграммы)» появляется кругляш нового месяца, а каждая покупка и правка сразу обновляет историю. В Apps Script нужно заходить, только если захочешь поставить новую версию скрипта.
